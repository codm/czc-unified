    Firmware Updates

    Check for and install the latest firmware for the two chips on your CZC.

    ESP

    The ESP32 is the main chip on the CZC. It runs this firmware, provides Wi-Fi/Ethernet connectivity and the web interface, and hosts the Thread Border Router application.

    RCP

    The Radio Co-Processor (RCP) is a separate CC2652P7 chip dedicated to the IEEE 802.15.4/Thread radio. It is connected to the ESP32 via UART and controlled using the Spinel protocol.
